# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The security of OSINT processing, API credential storage, and cognitive twin vaults is taken seriously.

If you discover a security vulnerability within `who??`, please do **not** open a public issue. Instead, report it privately:

1. Send an email with details, reproduction steps, and potential impact to **muctebaozdemir@gmail.com** or use the GitHub [Private Vulnerability Reporting](https://github.com/tilkiii/the-project-who/security/advisories/new) feature.
2. Please include:
   - Type of vulnerability (e.g. injection, credential leak, path traversal)
   - Step-by-step reproduction instructions or proof-of-concept
   - Affected modules or CLI subcommands
3. You will receive an initial response within 48 hours acknowledging receipt.
4. Coordinated disclosure will be arranged once a patch has been verified and released.
